인물 그림 넣는 곳 (직업마다 한 장씩)
- 파일 이름: 직업id.png  (hairdresser, cook, busdriver, cleaner, doctor, firefighter, police)
- 직업 데이터(data.js)의 "person": "images/직업id.png" 에 적혀 있는 파일을 사용. 없으면 임시 모양을 사용
- 크기 1000 x 1100 px, PNG, 바깥 배경은 투명, 사람 안쪽은 흰색
- 사람은 가운데, 발 아래 y≈1070, 높이 약 920~980px, 폭 약 400~450px
- 손 자리는 가로 29%/71%, 세로 66% 근처 (data.js의 slots로 조정)
