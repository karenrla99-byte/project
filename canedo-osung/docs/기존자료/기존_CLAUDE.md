# CANE DO (흰지팡이와 배우는 배려 방법 알기)

## 목적
10월 15일 흰지팡이의 날, 초등학생이 시각장애 이해와 배려 방법을 게임으로 익히는 웹앱.
특수교사 정은이 만든다. 모든 판단 기준은 "흰지팡이의 날 수업에 쓸 수 있는가"이다.

## 자료 (먼저 읽기)
- docs/기획서_v5.md : 전체 기준. 충돌하면 이 문서가 우선
- docs/디자인_브리프.md, design/ : 화면 디자인 기준
- docs/퀴즈_해설_검토본.md : 모든 문제·보기·정답·해설·힌트 문구. 한 글자도 바꾸지 말고 그대로 쓰기 (기본 글 / 쉬운 글 두 가지)
- docs/점자_활동_자료.md : 점자표와 이름 변환 규칙

## 반드시 지킬 규칙
1. 결과물은 index.html 한 파일(CSS·JS·이미지 모두 포함). 넷리파이 드래그 배포용.
2. 1280×720 가로 화면 기준, 창 크기에 맞춰 비율 확대/축소. 세로 화면은 "가로로 돌려 주세요" 안내.
3. 모든 화면 하단에 저작권 표시: "© 2026 특수교사 은티 · @special_eun_t" (이것만). 인스타 링크는 첫 화면에서만 클릭되고, 다른 화면에서는 글자만 보인다.
4. 그림은 코드로 그린 도트(픽셀) 그림. 16×16 도트를 확대, image-rendering: pixelated. 메이플스토리 등 기존 게임의 캐릭터·에셋은 쓰지 않고 오리지널로만.
5. 흰지팡이는 빨간 줄 없는 순수한 흰색으로 그린다.
6. 시각장애인을 불쌍하거나 우스꽝스럽게 표현하지 않는다.
7. 이동: ← →, Space(점프, 2단 점프), ↓+Space(아래로 내려가기), ↑/Enter(포털). 마우스 클릭도 되게.
8. 넣지 않는 것: "포털로 바로 가기" 버튼, 점프 난이도 완화 기능.
9. 설정: 글 종류(쉬운 글/기본 글), 글자 크기, 소리(읽어 주기). 모든 글은 선택한 글 종류로 보여준다.
10. 저장은 localStorage(try/catch로 감싸기). 서버·로그인 없음.
11. 기획서의 「검토」 표시와 "확인 필요" 항목은 임의로 확정하지 말고 표시해 두거나 정은에게 물어본다.
12. 점자 가게는 선택 포털. 완성 전에는 "한글 점자의 날(11월 4일)을 맞이하려고 준비 중이에요" 안내판(가게 안내 문구 느낌)만 보여준다.
13. 겹받침 글자는 점자 변환 시 "이 글자는 준비 중이에요"로 표시.

## 작업 방식
- 한 번에 전부 만들지 말고 단계별로 만든다. 한 단계가 끝나면 실행 방법을 알려 주고 정은의 확인을 기다린다.
- 쉬운 한국어로 짧게 보고한다. 코드 설명은 정은이 물을 때만.
- 수정할 때는 해당 부분만 고치고 다른 부분은 건드리지 않는다.
