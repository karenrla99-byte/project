# 점자 활동 자료 (검토용)

기준: 한국 점자 규정(문화체육관광부 고시, 국립국어원 해설서). 아래 표는 규정과 공개 정리 자료를 대조해 만들었고, 활동에 쓰기 전 점자 전문가나 점자도서관 자료로 한 번 더 확인하길 권해요.

## 1. 점자는 이렇게 생겼어요
- 점 6개가 세로 3칸 × 가로 2줄로 놓여 있어요. 칸 하나가 "한 글자 조각"이에요.
- 점 번호: 왼쪽 위에서 아래로 1·2·3, 오른쪽 위에서 아래로 4·5·6
- 읽을 때는 책 읽을 때와 같이 왼쪽에서 오른쪽으로 읽어요. 점필로 종이에 찍어 점자를 쓸 때는 뒤집어서 써요. (앱에서는 읽는 방향만 제시)

## 3. 쉬운 규칙 5가지 (아이들용)
1. 점자는 점 6개로 만들어요.
2. 한 글자는 **첫소리 → 모음 → 받침** 순서로 이어서 써요. 예) 길 = ⠈ ⠕ ⠂
3. 첫소리 **ㅇ은 쓰지 않아요.** 예) 우 = ⠍ (ㅜ만)
4. 받침은 첫소리와 **모양이 달라요.** 예) ㄱ 첫소리 ⠈, ㄱ 받침 ⠁
5. **ㅏ는 줄여 써요.** 나·다·마·바·자·카·타·파·하는 ㅏ를 쓰지 않아요. 예) 다 = ⠊, 하나 = ⠚⠉
   - **특별 글자 2개**: 가 = ⠫, 사 = ⠇

## 4. 심화(필요할 때만)
- ㅏ 줄임의 예외: 뒤 글자가 모음(ㅇ)으로 시작하면 ㅏ를 써요. 예) 마음 = ⠑⠣⠪⠢
- 줄임 글자(약자) 14개와 특별 글자 가·사: 아래 표 참고

### 줄임 글자(약자) — 심화
자주 쓰는 글자를 점 한 칸으로 줄여 쓴 글자예요. 첫소리가 있으면 앞에 첫소리를 쓰고, 약자 칸을 이어서 써요.

| 글자 | 점자 | 점 | 글자 | 점자 | 점 |
|---|---|---|---|---|---|
| 억 | ⠹ | 1·4·5·6 | 언 | ⠾ | 2·3·4·5·6 |
| 얼 | ⠞ | 2·3·4·5 | 연 | ⠡ | 1·6 |
| 열 | ⠳ | 1·2·5·6 | 영 | ⠻ | 1·2·4·5·6 |
| 옥 | ⠭ | 1·3·4·6 | 온 | ⠷ | 1·2·3·5·6 |
| 옹 | ⠿ | 1·2·3·4·5·6 | 운 | ⠛ | 1·2·4·5 |
| 울 | ⠯ | 1·2·3·4·6 | 은 | ⠵ | 1·3·5·6 |
| 을 | ⠮ | 2·3·4·6 | 인 | ⠟ | 1·2·3·4·5 |

- **특별 글자 2개**: 가 ⠫ (1·2·4·6), 사 ⠇ (1·2·3)
- 예) 눈 = ⠉⠛ (ㄴ + 운), 손 = ⠠⠷ (ㅅ + 온), 친구 = ⠰⠟⠈⠍ (ㅊ + 인, ㄱㅜ), 공 = ⠈⠿ (ㄱ + 옹)
- 약자 한 칸에는 **모음과 받침이 함께** 들어 있어요. 예) 운 = ㅜ + ㄴ → 그래서 눈 = ㄴ + 운(⠉⠛), 받침 ㄴ을 따로 쓰지 않아요.

### 쌍자음(된소리) — 된소리표 ⠠ 하나만 앞에 붙이면 돼요
| 쌍자음 | 점자 | 만드는 법 |
|---|---|---|
| ㄲ | ⠠⠈ | ⠠ + ㄱ |
| ㄸ | ⠠⠊ | ⠠ + ㄷ |
| ㅃ | ⠠⠘ | ⠠ + ㅂ |
| ㅆ | ⠠⠠ | ⠠ + ㅅ |
| ㅉ | ⠠⠨ | ⠠ + ㅈ |

- 예) 까치 = ⠠⠫⠰⠕ (까 = ⠠ + 가 약자 ⠫), 아빠 = ⠣⠠⠘ (ㅏ 줄임 규칙 적용), 쓰기 = ⠠⠠⠪⠈⠕
- **받침**으로 쓰는 쌍자음은 따로 써요: ㄲ 받침 = ⠁⠁, ㅆ 받침 = ⠌
- 「검토」 쌍자음 뒤 ㅏ 줄임(따·빠·짜), 까·싸의 가·사 약자, 받침 ㅆ·ㄲ 표기가 맞는지 점자 전문가 확인 필요
- 겹받침(ㄳ ㄵ 등), 붙임표 등은 이번 활동에서 다루지 않음

## 6. 활동 구성 (선택 포털 "점자 가게", 약 8분)

**입장 직후 소개 카드 (30초)**
- 제목: **11월 4일은 한글 점자의 날**
- 기본 글: 한글 점자인 「훈맹정음」은 1926년 11월 4일에 반포되었어요. 송암 박두성 선생님과 제자들이 만들었어요. 올해는 100주년이에요.
- 쉬운 글: 한글 점자의 이름은 「훈맹정음」이에요. 1926년 11월 4일에 세상에 알렸어요. 박두성 선생님과 제자들이 만들었어요. 올해는 100년째예요.
- 「검토」 만든 사람 표현(박두성 선생과 제자들)과 "올해 100주년" 표현 확인

1. **점 6개 알아보기(1분)**: 점을 눌러 켜고 끄며 번호 확인. 이야기: "점자는 손끝으로 읽는 글자예요."
2. **읽어 보기·찍어 보기(4~5분)**: 표를 보며 낱말 읽기 3개 + 점 찍기 3개. 3번째 낱말부터 ㅏ 줄임 규칙 카드 제시
   - 낱말은 **자음·모음·받침을 분리해서** 보여 줘요. 그래야 표에서 찾기 쉬워요.
   - 예) 길 → ㄱ(첫소리) + ㅣ(모음) + ㄹ(받침) / 나무 → ㄴ + (ㅏ 줄임) / ㅁ + ㅜ
   - 이중모음이 있는 낱말(예: 사과의 ㅘ)은 모음 칸에 이중모음으로 보여 줘요.
3. **내 이름 점자(2분)**: 별명 입력 → 앱이 점자로 변환(약자 포함) → 점 찍어 보기 → 면허증에 점자 이름 표시
- 규칙은 5가지만 먼저 보여 주고, 특별 글자(가·사)와 약자는 "특별 글자 카드"로 필요할 때만 펼침
- 이름 변환은 약자·ㅏ 줄임 규칙을 앱이 처리. 쌍자음은 된소리표로 처리하고, 겹받침이 있는 글자는 아직 지원하지 않고 "이 글자는 준비 중이에요" 안내를 띄운 뒤 다른 별명을 쓰게 안내 (겹받침 규칙은 정리해 두었고, 전문가 확인 후 추가 예정)

## 7. 확인이 필요한 것
- 한글 점자의 날 소개 카드(6번 앞부분)의 날짜(1926년 11월 4일)와 만든 사람(송암 박두성 선생과 제자들)은 기사로 확인함(경인일보, 경향신문, 뉴시스, 아주경제). "반포"와 "발표"를 기사마다 섞어 쓰므로 앱 문구는 "반포"로 정함. 올해 100주년이라는 표현은 기사의 주년 계산(2024년 98주년)에서 따름
- 점자표·약자·이름 변환 결과를 점자 전문가 또는 점자도서관에서 검수
- 표기: 앱에서는 읽는 방향 기준 점으로 보여 줌
