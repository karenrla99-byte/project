**제목: CANE DO** · **부제: 흰지팡이와 배우는 배려 방법 알기** (확정)

**10월 15일 흰지팡이의 날** 기념 · 초등학생 · 혼자 하는 픽셀 RPG 점프 모험

> 이 앱은 흰지팡이의 날을 위해 만든다. 시작 화면·마을·해내다 광장·면허증 어디서든 "10월 15일 흰지팡이의 날"이 드러나야 한다.

## 2. 방향 원칙 (시야 효과 + 설명 카드)
- 학생은 **언제나 "도와주는 사람(친구)" 역할**. 눈을 가리는 체험이 아니라 "이렇게 보이는 친구도 있어요"를 이해하는 장치
- **시야 효과는 유지**: 길 안내 퀘스트(5~7)에서 안내받는 친구의 보이는 모습을 화면에 적용 (황반변성·백내장·터널 시야 등)
- **효과가 나타날 때마다 설명 카드가 먼저 뜸**. 카드 내용 예: 이름, "이렇게 보이는 친구도 있어요", "보이는 정도는 사람마다 달라요", "그래서 말로 구체적으로 알려 주면 도움이 돼요"
  - 효과 적용 전 카드를 한 번 보여 주고, 끌 수 있는 버튼 제공(설정: 시야 효과 켜기/끄기)
  - 어둡거나 깜깜한 화면은 오래 두지 않고, 깜빡임 없이 부드럽게
  - 검토 필요: 각 시야 유형의 설명 문구, "모든 시각장애인이 그렇게 보이는 건 아니다"는 문구가 빠지지 않게
- "눈 감고 따라가기"는 안내 순서를 배우는 **"함께 걷기"** 로 교체
- 모든 문구는 "~하는 친구", "~해 주면 좋아요"처럼 존중하는 표현 ("불쌍한", "극복" 금지)
- **마무리 화면**: "시각장애가 있는 친구도 우리와 같은 일상을 살아가요. 필요한 도움은 그 친구에게 먼저 물어봐요." + 맨 끝에 **CANE DO / 흰지팡이와 배우는 배려 방법 알기**
  - 그 사이에 짧은 안내글 한 줄(작게, 지나가듯): "CANE DO는 지팡이와 함께 CAN DO, 해낸다는 뜻이에요."

## 3. 이동 방식
| 조작 | PC | 태블릿·모바일(가로) |
|---|---|---|
| 걷기 | ← → | 좌측 ◀ ▶ |
| 점프 / 2단 점프 | Space (공중에서 한 번 더) | 우측 점프 버튼(공중에서 한 번 더) |
| 아래 발판으로 | ↓ + Space | 아래 버튼 |
| 포털 입장 | ↑ 또는 Enter | 포털 앞 입장 버튼 |

- 2단 점프를 쓰므로 **높은 발판(3~4단)** 까지 배치 가능. 별과 숨은 길을 높은 곳에 둠
- 별 줍기: 줍기만 하고 점수·등급에는 반영하지 않음 (면허증에 "모은 별" 표시만)
- **"포털로 바로 가기" 버튼은 넣지 않음** (결정). 점프 난이도 대응은 따로 고려하지 않음
- 앞 퀘스트를 깨야 다음 길이 열림

## 5. 퀘스트 상세
- **퀴즈 팝업**: 마을 위에 RPG 대화창. 질문·선택지·해설, ✕로 닫기, 숫자키 선택, 읽어주기
- **같이 밥 먹기(3)**: 식판 음식 위치를 **기준이 되는 음식 + 위치**로 구체적으로 설명 (예: "국 위에 김치", "밥에서 1시 방향에 계란말이"). 시계 방향은 예시 중 하나로만 사용. 「저기」「여기」만 쓰면 되묻기
- **길 안내(5~7)**: 코딩 로봇처럼 "앞으로 ○걸음, 오른쪽으로 돌아서 ○걸음" 입력. 친구가 칸 위를 걸어감. 시야 효과 + 설명 카드 적용. 문·계단·창문이 있다는 말도 해야 클리어. 문턱(턱)도 장애물로 넣음 (확정)
- **함께 걷기(8)**: 보행자를 안내하는 순서 카드 5장을 올바른 순서로 맞춤
  1. 인사하고 이름을 말한 뒤 "도와드릴까요?" 하고 묻기
  2. "제 팔꿈치(또는 어깨)를 잡으세요." 하고 팔을 내밀고, 보행자의 손을 내 팔꿈치나 어깨에 둠
  3. 보행자보다 반 걸음 앞에서 걷기
  4. 계단·문·문턱(턱)·좁은 길 앞에서는 잠깐 멈춰서 앞에 무엇이 있는지 말해 주고 가기
  5. 의자에 앉을 때는 의자 옆에 서서 보행자의 손을 의자에 올려 주기

## 6. 글 난이도: 쉬운 글 / 기본 글
- 설정에서 선택(처음 시작할 때 한 번 물어보기도 가능). 기본값은 기본 글
- 퀴즈 질문·선택지·해설, 퀘스트 안내, 피드백, 힌트에 **두 버전** 작성 (면허증 고정 문구는 한 가지)
- 쉬운 글 기준: 한 문장 짧게, 어려운 낱말은 쉬운 낱말로, 설명은 2문장 이내, 예시 중심
- 기본 글 기준: 고학년까지 이해할 수준, 이유와 설명을 조금 더 자세히 (예: 스마트폰 해설에서 TTS 설명)
- 읽어주기(TTS)는 선택한 글 버전을 그대로 읽음

## 7. 면허증 (이름: CANE DO)
- 이름·캐릭터·등급·퀘스트 배지·날짜·모은 별
- **알게 된 것 한 줄 / 실천할 것 한 줄** (20자 안팎):
  - **기본 글**: 학생이 **예시 없이** 직접 입력 (예시를 주면 그대로 쓰기 때문)
  - **쉬운 글**: 보기를 선택하면 입력칸에 자동으로 입력 (보기 문구는 "퀴즈·해설 검토본" 6번)
- 등급: 새싹 길잡이 → 든든 길잡이 → 빛나는 길잡이 (틀린 횟수·힌트가 적을수록 높음. 부딪힘 항목은 삭제 검토)
- 점자 가게를 한 학생은 점자 이름도 표시
- PNG 저장

## 8. 점자 가게 (선택 포털)
자세한 표와 규칙은 별도 문서 "점자 활동 자료" 참고.
0. **소개 카드**(입장 직후, 30초): 제목 "11월 4일은 한글 점자의 날". 한글 점자 「훈맹정음」은 1926년 11월 4일에 반포되었고, 송암 박두성 선생과 제자들이 만들었다는 내용 (기본/쉬운 글)
1. **점 6개 알아보기**(1분): 점 번호 1~6, 눌러서 켜 보기
2. **읽어 보기·찍어 보기**(4~5분): 낱말을 **자음·모음·받침으로 분리해서** 보여 주고 표에서 찾아 읽거나 점 찍기 (약자 없는 낱말)
3. **내 이름 점자**(2분): 별명(최대 4글자)을 입력하면 앱이 점자로 변환해 보여 주고 점 찍어 보기. 면허증에 점자 이름 표시
- 점자표: 첫소리·모음(**이중모음 포함**)·받침 / 심화: 약자, 쌍자음(된소리표 ⠠)
- 이름 변환: 약자·ㅏ 줄임·이중모음·쌍자음을 앱이 처리. **겹받침이 있는 글자는 준비 중** 안내
- 소요 약 8분, 선택 포털이라 하고 싶은 학생만 입장

### 점자 가게 "준비 중" 안내판 (완성이 안 될 경우)
- 점자 가게를 일단 만들어 보고, **완성하지 못하면 포털은 두되 입장하면 가게 안내판만** 보여 줌
- 가게 문 앞 팻말 형식 (픽셀 팻말 그림 + 대화창)
  - 팻말 제목: **영업 준비 중**
  - 기본 글: "점자 가게는 11월 4일 한글 점자의 날을 맞이해 문을 열 준비를 하고 있어요. 조금만 기다려 주세요!"
  - 쉬운 글: "점자 가게는 지금 준비 중이에요. 11월 4일 한글 점자의 날에 문을 열어요. 조금만 기다려 주세요!"
  - 닫기 버튼 문구: "다음에 올게요"
- 필수 퀘스트와 면허증에는 영향 없음
- 확인 필요: 실제로 11월 4일에 여는지 여부

## 9. 소요 시간 (대략, 시험 사용 후 조정)
- 필수 경로: 약 25분 (퀴즈 팝업 11문제, 반찬 1회, 길 안내 3회, 함께 걷기 1회, 길 위 NPC 몇 명, 이동)
- 점자 가게 포함: 약 33분
- 40분 수업이면 필수 경로 + 면허증, 점자는 남는 시간·다음 차시 활동으로 제안

## 11. 접근성
- 읽어주기, 키보드 조작, 포커스 표시, 화면 읽기용 알림
- 색에만 의존하지 않기, 고대비, 움직임 줄이기

## 12. 픽셀 RPG 아트
- 16×16 픽셀 스프라이트, 남색 외곽선 + 노랑 포인트, 픽셀 한글 글꼴(실패 시 일반 글꼴)
- 캐릭터 8종, 길 안내 친구(흰지팡이를 든 모습), 포털 건물, 마을 소품, 반찬 5종, 장애물(문턱 포함), 점자블록, 안내견, 아이콘
- **표현 주의**: 친구 캐릭터를 불쌍하거나 우스꽝스럽게 그리지 않기. 선글라스·흰지팡이는 평범한 모습으로

## 14. 화면 목록 (디자인용)
1. 시작: 로딩 바 → START, 제목 CANE DO + 부제, 10월 15일 흰지팡이의 날, 인스타 링크(클릭 가능)
2. 이름·캐릭터 선택 (캐릭터 8종)
3. 마을(횡스크롤 점프 맵): 발판, 별, 포털, 길 위 NPC, 잠금 문
4. 퀴즈 팝업: 주민 얼굴·이름표, 질문, 선택지(OX 포함), 힌트, 해설, 읽어주기, ✕
5. 같이 밥 먹기: 식판 그림 + 설명 입력창 + 음성 입력 버튼
6. 길 안내 3종: 격자 지도, 친구 캐릭터, 명령 입력창·명령 카드, 힌트, 시야 효과, 설명 카드
7. 함께 걷기: 순서 카드 5장 끌어 맞추기
8. 점자 가게: 소개 카드, 점 6개 칸, 해독표(자모 분리), 이름 변환 결과, 준비 중 안내판
9. 면허증: 이름·캐릭터·등급·배지·별·한 줄 두 개·(점자 이름), 저장 버튼
10. 마무리 화면: 메시지 한 줄 + CANE DO / 부제
11. 설정 창
- 모든 화면 공통: 좌측 상단 전체화면 버튼, 우측 상단 설정 버튼, 하단 표기

## 15. 확인이 필요한 것
1. 시야 효과별 설명 카드 문구 (초안 작성 후 검토)
2. 같이 밥 먹기 채점을 "기준이 되는 음식 + 위치"로 바꾼 것 확인
3. 점자표·약자·쌍자음·이중모음·이름 변환은 점자 전문가 확인 권장 (겹받침은 추후)
4. **일정**: 흰지팡이의 날(10월 15일)에 맞추려면 시간이 짧음. 필수 범위를 먼저 완성하고 점자 가게는 마지막에 붙이는 순서 권장
