# CANE DO 디자인 브리프

디자인 담당에게 넘기는 문서예요. 기획 전체는 "기획서 v5"에 있고, 이 문서는 **화면을 만드는 데 필요한 것만** 모았어요.

## 1. 한 줄 소개
**CANE DO** · 부제 "흰지팡이와 배우는 배려 방법 알기"
10월 15일 흰지팡이의 날을 맞아, 초등학생이 혼자 하는 **픽셀 RPG 점프 모험** 웹앱. 마을을 걸으며 퀘스트를 깨고, 시각장애가 있는 사람을 어떻게 대하고 도울지 배운다.

## 2. 사용자와 환경
- 대상: 초등학생 (저학년~고학년), 혼자 하는 게임
- 기기: 전자칠판, 태블릿 가로, 데스크탑 가로, 모바일 가로
- 기준 화면: **1280×720 가로**, 창 크기에 맞춰 비율대로 확대·축소. 세로면 "가로로 돌려 주세요" 안내 화면
- 단일 HTML 파일로 배포되므로 **이미지 파일 없이 코드로 그릴 수 있는 픽셀 그림**이 좋음 (16×16 스프라이트를 정수배 확대, 선명한 도트)

## 3. 분위기와 스타일
- **분위기: 메이플스토리 같은 사이드 스크롤 픽셀 RPG.** 밝고 아기자기하고 동글동글 귀여운 느낌. 파란 하늘, 초록 언덕, 포근한 마을, 반짝이는 별 줍기
  - 느낌만 참고해요. 메이플스토리의 캐릭터·몬스터·건물·로고·UI를 그대로 따라 그리지 말고, **CANE DO만의 오리지널 캐릭터와 마을**로 그릴 것
- **스타일: 흰지팡이의 색이 가장 눈에 띄는 디자인.** 이 앱의 주인공 색은 **흰색**
  - 흰색(크림 포함)을 브랜드 대표색으로: 로고, START 버튼, 대화창 안쪽, 면허증, 길 안내 친구의 흰지팡이가 화면에서 가장 밝고 또렷하게 보이게
  - 흰색이 묻히지 않도록 **짙은 남색 외곽선**과 어두운 배경(밤하늘, 짙은 초록)을 함께 써서 대비를 줌
  - 포인트 색은 한두 가지만, 소량으로 (제안: 지팡이 끝·띠에 쓰는 빨강, 별·강조에 쓰는 노랑). 빨강·흰색 **줄무늬 지팡이**는 시청각장애를 나타내는 지팡이로 쓰이는 경우가 있으니 쓰지 않고, 일반 흰지팡이(흰 몸체 + 손잡이·끝 포인트)로 그릴 것 「검토」
- 제안 팔레트(바꿔도 됨): 흰색 `#FFFFFF`, 크림 `#FFFDF2`, 남색 외곽선 `#1B2A5B`, 하늘 `#8FD3F4`, 초록 `#6CC070`, 포인트 빨강 `#E5484D`, 포인트 노랑 `#FFD84D`, 흙/나무 갈색
- 창(UI): 두꺼운 남색 테두리 + 흰색/크림 안쪽 면, 모서리가 각진 RPG 대화창과 버튼. 강조 버튼은 흰색 면 + 포인트 색 테두리
- 글꼴: 픽셀 한글 글꼴(예: 갈무리 계열). 못 불러오면 일반 고딕으로 대체되어도 깨지지 않게
- **글씨 크기 3단계**(설정)로 커지므로 팝업·버튼에 여유 공간 필요
- **고대비 모드**, **움직임 줄이기** 모드가 있음 (색만으로 구분하지 않고 아이콘·문구를 함께 표시)

## 4. 표현할 때 꼭 지킬 것
- 시각장애가 있는 친구 캐릭터를 **불쌍하거나 우스꽝스럽게 그리지 않기**. 선글라스와 흰지팡이를 든 평범하고 당당한 모습
- 학생(플레이어)은 늘 **도와주는 친구**
- "불쌍한", "극복", "장애를 체험" 같은 느낌 금지
- 시야 효과(황반변성·백내장·터널 시야 등)가 나올 때는 **먼저 설명 카드**가 뜨고, 화면이 깜깜하게 오래 있거나 깜빡이지 않게

## 5. 모든 화면 공통
- 좌측 상단: **전체화면 버튼**
- 우측 상단: **설정 버튼**
- 하단: `© 2026 특수교사 은티 · @special_eun_t`
  - 인스타 링크는 **첫 화면에서만 클릭** 가능, 다른 화면에서는 글자만 보임
- 화면 어디에서든 10월 15일 흰지팡이의 날이 드러나야 함 (시작·마을·광장·면허증)

## 6. 화면별 요구

### 6-1. 시작 화면
- 밤하늘 + 언덕 배경, 로고 **CANE DO** + 부제, "10월 15일 흰지팡이의 날"
- 흰지팡이를 든 친구가 로딩 바를 따라 걸어가 길잡이 캐릭터 옆에 서면 **START** 버튼이 나타남
- 진짜 게임 같은 로딩 → START 흐름

### 6-2. 이름·캐릭터 선택
- 이름 입력, 캐릭터 8종 중 선택 (걷는 모습 2프레임)

### 6-3. 마을 (횡스크롤 점프 맵)
- 가로로 긴 한 줄 맵. 땅 + 낮은 발판 + 높은 발판(3~4단), **2단 점프**로 오르내림
- 발판 위·점프 구간에 **별**
- 퀘스트 **포털 건물 9개**(색을 다르게). 앞 퀘스트를 깨야 다음 길이 열리고, 잠긴 곳은 잠금 표시
- 길 위 **퀴즈 NPC 5명**, 마을 소품(나무·덤불·꽃·가로등·구름·언덕)
- 화면 안내 버튼: 조작 안내(← → / Space / ↓ / ↑·Enter) 표시, 모바일은 좌측 ◀ ▶, 우측 점프 버튼
- 포털 앞에 이름표와 아이콘이 뜸

포털 목록
| 순서 | 이름 | 유형 |
|---|---|---|
| 1 | 알쏭달쏭 마을 | 퀴즈(OX 4) |
| 2 | 흰지팡이 가게 | 퀴즈(4) |
| 3 | 같이 밥 먹기 | 반찬 위치 설명 |
| 4 | 마음 대화 벤치 | 퀴즈(3) |
| 5 | 길 안내 코딩 | 길 안내 |
| 6 | 문과 계단 | 길 안내 |
| 7 | 창문 찾기 | 길 안내 |
| 8 | 함께 걷기 | 순서 카드 5장 |
| 선택 | 점자 가게 | 점자 활동 (안 해도 됨) |
| 끝 | 해내다 광장 | 면허증 |

### 6-4. 퀴즈 팝업
- 마을 화면 위에 뜨는 **RPG 대화창**, 뒤의 마을은 어둡게
- 구성: 주민 얼굴(픽셀)+이름표 / 질문 / 선택지(OX 또는 ①②③) / 힌트 / 정답·오답 표시 / 해설 / 읽어주기 버튼 / ✕ 닫기
- 숫자키 1·2·3으로도 선택
- 글씨 크기를 키워도 넘치지 않게

샘플 (OX)
> 문제: 점자블록 위에 자전거, 킥보드, 물건을 놓아도 괜찮다.
> 선택: O / X → 정답 X
> 해설: 아니에요. 점자블록은 길을 확인하는 길이에요. 걸려서 넘어질 수 있어 위험해요. 점자블록 위에는 아무것도 두지 않아요.

샘플 (3지선다)
> 문제: 흰지팡이의 날은 언제일까요?
> ① 4월 20일 ② 10월 15일 ③ 11월 4일

### 6-5. 같이 밥 먹기
- 식판 그림(밥, 국, 반찬 3가지 = 반찬 5종: 김치·콩나물·오리고기·밥·국)
- 설명 입력창(키보드 직접 입력, 음성 입력 버튼), 힌트 단계, 제출 후 피드백
- 시각장애가 있는 친구가 앉아 있는 모습

### 6-6. 길 안내 (3종: 길 / 문·계단 / 창문)
- **격자 지도** 위에 친구 캐릭터, 장애물(자전거·화분·공사콘·의자·책상·소화기·가방·쓰레기통·벽·문·계단·문턱·창문·횡단보도), 도착 지점
- 아래에 **명령 입력창**: "앞으로 ○걸음, 오른쪽으로 돌아서 ○걸음" (코딩 로봇처럼). 명령 카드(앞으로/오른쪽/왼쪽/뒤로 돌기)를 눌러 넣을 수도 있음
- 입력한 대로 친구가 칸 위를 걸어가는 모습, 부딪히면 피드백, 힌트 3단계
- **시야 효과 + 설명 카드**: 효과 적용 전에 카드가 먼저 뜨고, 효과 끄기 버튼이 있음

### 6-7. 설명 카드 (시야 효과 안내)
- 구성: 효과 이름 / "이렇게 보이는 친구도 있어요" / "보이는 정도는 사람마다 달라요" / "그래서 말로 구체적으로 알려 주면 도움이 돼요" / [알겠어요] [효과 끄기]
- 문구는 초안이며 정은 선생님이 검토 예정

### 6-8. 함께 걷기
- 순서 카드 5장을 끌어서(또는 눌러서) 올바른 순서로 맞추기
- 카드는 한 줄씩 읽기 쉬운 크기. 순서가 맞으면 안내 그림이 이어짐
카드 문구 예 (기본)
1. 인사하고 이름을 말한 뒤 "도와드릴까요?" 하고 묻기
2. "제 팔꿈치를 잡으세요." 하고 팔을 내밀기
3. 보행자보다 반 걸음 앞에서 걷기
4. 계단·문·문턱 앞에서 잠깐 멈추고 앞에 무엇이 있는지 말하기
5. 의자 옆에 서서 보행자의 손을 의자에 올려 주기

### 6-9. 점자 가게 (선택 포털)
- **소개 카드**: 제목 "11월 4일은 한글 점자의 날" + 짧은 글 두어 줄
- **점 6개 칸**: 세로 3칸×가로 2줄, 번호 1~6 (왼쪽 위에서 아래로 1·2·3, 오른쪽 4·5·6). 눌러서 켜고 끄기
- **해독표**: 첫소리·모음(이중모음 포함)·받침 표. 낱말은 **자음·모음·받침으로 나눠서** 보여 줘서 표에서 찾기 쉽게
- **내 이름 점자**: 이름을 입력하면 점자로 변환해 보여 주고 따라 찍어 보기
- 앱에서는 점자를 **읽는 방향(왼쪽→오른쪽)**으로만 보여 줌
- 샘플 점자: 길 = ⠈⠕⠂, 나무 = ⠉⠑⠍
- **"영업 준비 중" 안내판**: 점자 가게를 못 만들 경우 보여 줄 가게 문 앞 팻말 + 대화창
  - "점자 가게는 11월 4일 한글 점자의 날을 맞이해 문을 열 준비를 하고 있어요. 조금만 기다려 주세요!" / 버튼 "다음에 올게요"

### 6-10. 면허증
- 이름·캐릭터·등급(새싹/든든/빛나는 길잡이)·퀘스트 배지·날짜·모은 별
- **알게 된 것 한 줄 / 실천할 것 한 줄** (20자 안팎)
  - 기본 글: 빈 입력칸 (예시 없음)
  - 쉬운 글: 보기 칩을 누르면 칸이 채워짐
- 점자 가게를 한 학생은 **점자 이름** 표시
- 이미지(PNG)로 저장하는 버튼
- 면허증 이름: **CANE DO** (카드 맨 위에 CANE DO, 아래에 "면허증")

### 6-11. 마무리 화면
- 메시지: "시각장애가 있는 친구도 우리와 같은 일상을 살아가요. 필요한 도움은 그 친구에게 먼저 물어봐요."
- 메시지 아래에 작은 안내글 한 줄, 눈에 띄지 않게 지나가듯: "CANE DO는 지팡이와 함께 CAN DO, 해낸다는 뜻이에요."
- 맨 끝에 **CANE DO** + "흰지팡이와 배우는 배려 방법 알기"

### 6-12. 설정 창
글 난이도(쉬운 글/기본 글) · 시야 효과 켜기/끄기 · 글자 읽어주기(TTS)와 속도 3단계 · 글씨 크기 3단계 · 고대비 · 움직임 줄이기 · 효과음 · 음성 입력 버튼 보이기 · 이름·캐릭터 바꾸기 · 처음부터

## 7. 필요한 그림(에셋) 목록
- 캐릭터 8종(걷기 2프레임), 흰지팡이·선글라스를 한 길 안내 친구, 안내견
- 퀴즈 주민 얼굴(마을 주민 몇 종), NPC 5종
- 포털 건물 9채(색 구분), 마을 소품, 땅·발판·구름·언덕
- 반찬 5종(김치·콩나물·오리고기·밥·국), 식판
- 장애물·점자블록(노란 블록)·횡단보도·문·계단·문턱·창문
- 아이콘: 별, 체크, 잠금, 전체화면, 설정, 읽어주기(스피커), 음성 입력(마이크), 힌트
- 점자 칸(점 6개), 팻말
- 면허증 틀, 등급 배지 3종, 퀘스트 배지 8종

## 8. 아직 정해지지 않은 것
- 시야 효과별 설명 카드 문구 최종본
- 점자 가게 완성 여부 (미완성이면 안내판만 보임)

## 9. 디자인에서 받고 싶은 것
- 화면 6-1 ~ 6-12 디자인(가로 1280×720 기준)
- 창/버튼/카드 등 **공통 UI 규칙**(색, 테두리 두께, 글꼴 크기 3단계)
- 마을과 캐릭터의 **픽셀 스타일 기준 한 장**(캐릭터·건물·소품 샘플)
- 고대비 모드, 글씨 크기가 커졌을 때의 모습
